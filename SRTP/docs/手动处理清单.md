## 事项 5：CMeKG 全量图谱恢复与导入（可选增强）

**背景**：仓库新增 `cmekg-v5.2-no-constraints/cmekg-v5.2-no-constraints.dump` 是 Neo4j 5.x 图库 dump，
需在本地恢复后用 ETL 脚本转换，再导入云数据库 `cme_kg_medicines`，以提升禁忌分析覆盖率。
**当前本机为 JDK 11，需另装 JDK 17+ 才能跑 Neo4j 5.x。**

> 详细说明见 `SRTP/scripts/cmekg-integration.md`，此处为精简步骤。

### 5.1 恢复 dump
```bash
# 安装 Neo4j 5.x Community + JDK 17，将 dump 放入 ./dumps/
neo4j stop
neo4j-admin database load cmekg --from-path=./dumps --overwrite-destination=true
neo4j start
```

### 5.2 探查图谱 schema 并校准配置
```bash
cd SRTP/scripts
npm install
# PowerShell:
$env:NEO4J_PASSWORD="你的Neo4j密码"; $env:CMEKG_DATABASE="cmekg"
node cmekgEtl.js --probe
```
据输出（标签 / 关系类型 / 属性）修改 `cmekgEtl.js` 顶部 `CONFIG`，或用环境变量覆盖。

### 5.3 抽取生成 JSON
```bash
node cmekgEtl.js
# 生成 SRTP/scripts/cmekg_seed_data.generated.json
```

### 5.4 导入云数据库
1. 删除生成 JSON 的 `_comment/_generatedAt/_count/import_instructions` 元字段，保留 `medicines` 数组。
2. 云开发控制台 → 数据库 → `cme_kg_medicines` → 导入。
3. 为 `name` 建唯一索引、`aliases` 建普通索引（见 `scripts/initDatabase.js`）。

> 若暂不集成全量图谱，现有 `cmekg_seed_data.json`（约 50 种药品）已可正常工作。

## 事项 6：回归测试清单

部署完成后，在微信开发者工具（模拟器或真机预览）逐项验证：

- [ ] **锁屏**：在「我的 → 隐私设置」开启密码锁，退后台再进入，确认跳转到 `packageA/pages/lock/lock`。
